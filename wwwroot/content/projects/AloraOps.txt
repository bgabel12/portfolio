<h5 class="mt-4">Overview</h5>
<p>AloraOps is a robust, cloud-enabled application designed to streamline manufacturing operations by integrating real-time machine data with an ERP system. The application consists of two primary modules: an <strong>Operator Module</strong> for shop-floor employees and a <strong>Manager Module</strong> for supervisors. These modules facilitate job tracking, employee time management, downtime reporting, quality control, and machine monitoring, ensuring seamless data flow between shop-floor activities and enterprise resource planning.</p>

<h5 class="mt-4">Operator Module</h5>
<ul class="mb-2">
  <li>Employee <strong>Clock-In & Clock-Out</strong> with real-time tracking.</li>
  <li><strong>Job and Machine Association</strong> to link active work orders to <strong>machine utilization</strong>.</li>
  <li><strong>Downtime Management</strong>, allowing operators to report and categorize production halts.</li>
  <li><strong>Job Timer Tracking</strong> to accurately log work hours for each task.</li>
  <li><strong>Parts & Scrap Submission</strong>, including a <strong>quality control approval workflow</strong>.</li>
  <li><strong>Job Notes & Annotations</strong>, enabling operators to document process insights.</li>
</ul>

<h5 class="mt-4">Manager Module</h5>
<ul class="mb-2">
  <li>Live Machine Monitoring with job progress and downtime alerts.</li>
  <li>Downtime Application & Approval for system-wide accuracy.</li>
  <li>Kiosk Management, assigning operator stations to machines.</li>
  <li>Quality Control & Part Approval before data syncs to the ERP.</li>
  <li>Comprehensive Job Tracking with status updates, progress bars, and historical data.</li>
</ul>

<h5 class="mt-4">Technical Architecture</h5>
            To ensure reliability and scalability, AloraOps leverages modern cloud-based and on-premise integrations:
<ul>
  <li>
    <strong>Frontend:</strong>
    <ul>
      <li>Built using Blazor WebAssembly (WASM) for an interactive, responsive user experience.</li>
      <li>Deployed as an Azure Static Web App for high availability.</li>
    </ul>
  </li>

  <li>
    <strong>Backend & APIs:</strong>
    <ul>
      <li>.NET Core (C#) for API development.</li>
      <li>Azure Functions (REST API) for retrieving ERP and machine data.</li>
      <li>Durable Functions Orchestration to manage transactional workflows efficiently.</li>
    </ul>
  </li>

  <li>
    <strong>ERP & Machine Data Integration:</strong>
    <ul>
      <li>Data Collection Gateway (On-Prem REST API) for receiving, transforming, and submitting AloraOps transactions to the ERP.</li>
      <li>Azure Hybrid Connection for secure, low-latency connectivity between cloud services and on-prem ERP systems.</li>
    </ul>
  </li>

  <li>
    <strong>Security & Deployment:</strong>
    <ul>
      <li>Auth0 for authentication and access control.</li>
      <li>Azure DevOps Pipelines (CI/CD) for automated build and deployment.</li>
    </ul>
  </li>
</ul>
