This architecture leveraged:
<ul>
  <li><strong>Azure Queues & Blob Storage</strong> for asynchronous messaging and configuration management.</li>
  <li><strong>Microservices</strong> to handle command processing, player status monitoring, and remote updates.</li>
  <li><strong>Secure API endpoints</strong> for managing device communication and remote control functions.</li>
</ul>

<p>
  This system allowed administrators to remotely configure players, send commands (e.g., reboots, content updates),
  and retrieve device status through a web-based management portal.
